# 云梭桌面端

云梭 Yunsuo 的 Windows 完整桌面客户端。桌面端内打开完整站点，并提供本地监控调度能力。

## 功能

- 首次启动填写登录地址、账号和密码，默认直接调用站点登录接口。
- 登录前服务器验证为可选开关；服务器开启并允许健康检查时可开启预检，受限环境可保持关闭。
- 登录 Token 使用 Windows `safeStorage` 加密保存在本机，下次启动自动注入，无需再次登录。
- 进入完整站点后可正常使用概览、智能转存、网盘账号、任务、分享库、我的空间、链接监控和管理员后台。
- 链接监控支持两种运行方式：
  - `云端监控`：由服务端调度器 7×24 小时巡检。
  - `本地监控`：由桌面端在线时每 15 秒触发到期检查；关闭桌面端后自动暂停。
- Token 在站内登录或退出后自动同步，本机不保存站点密码。
- 顶部菜单支持登录设置、刷新完整版、全屏、缩放和立即执行本地巡检。

## 使用

1. 运行 `YunsuoDesktop-1.1.1.exe`。
2. 输入云梭登录地址、账号、密码。
3. 按需开启「登录前验证服务器」，然后点击「登录并打开完整版」。
4. 登录后即可使用全部站点功能；下次启动会直接打开。

也可以在登录页点击「打开站点登录 / 注册」，在完整站点内完成登录或注册。首次运行若遇到 Windows SmartScreen，选择「更多信息」后确认运行。

## 本地开发

```powershell
npm install
npm start
npm run dist
```

验证源码语法：

```powershell
node --check src/main.js
node --check src/preload.js
node --check src/renderer.js
```

生成文件位于 `release/YunsuoDesktop-1.1.1.exe`。

## 安全说明

- 桌面端不保存站点密码。
- 登录 Token 通过 Windows 安全存储加密后写入本机 `connection.json`，不以明文落盘。
- 桌面端不保存百度、夸克、迅雷 Cookie；网盘账号与凭据仍由服务端加密管理。
- 第三方网盘接口可能调整，连接与转存能力取决于已部署的云梭服务版本。
