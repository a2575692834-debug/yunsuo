# 云梭本地版

云梭本地版是一个完全独立的 Windows 桌面程序。它不连接云梭服务器、不要求注册或登录，也不依赖 MySQL；用户数据、网盘 Cookie、转存记录和分享记录都保存在当前电脑上。

## 功能

- 百度网盘、夸克网盘、迅雷网盘扫码登录与 Cookie 导入。
- 同一网盘可保存多个 Cookie。
- 正则识别混合分享文案，可一次处理多个百度、夸克和迅雷链接。
- 按当天日期自动创建转存目录，也可指定固定目录。
- 转存完成后自动创建分享，支持永久有效、1/7/30 天和自定义 4 位提取码。
- 批量分享结果可复制，并可导出 TXT、CSV、Markdown。
- 本地文件浏览、搜索、重命名、删除、复制、移动和新建文件夹。
- 本地分享库与链接监控；关闭程序后本地监控暂停。
- 纸墨朱砂、青岚、玄金、夜航四套界面主题。

## 数据与隐私

- 网盘 Cookie 使用 Electron `safeStorage` 调用 Windows 数据保护能力加密后落盘。
- 除二维码、容量、网盘文件、转存与分享请求外，程序不会向任何第三方发送数据。
- 程序内不存在云梭登录接口，也不会连接 `localhost:18088`、MySQL 或现有云梭后端。
- 卸载程序默认不会删除本地数据，避免误删历史记录。

本地数据目录会在程序内「本地设置」页面显示，也可从侧边栏直接打开。

## 安装

运行 `YunsuoLocal-Setup-1.0.0.exe`，按安装向导选择目录、创建桌面快捷方式并完成安装。

由于安装包未购买代码签名证书，Windows SmartScreen 可能提示未知发布者。确认文件来源可信后，选择「更多信息」→「仍要运行」。

## 构建

```powershell
npm install
npm run dist
```

安装包输出：

```text
release/YunsuoLocal-Setup-1.0.0.exe
```

仅生成免安装版：

```powershell
npm run dist:portable
```

## 说明

第三方网盘接口可能随官方调整而变化。扫码、转存、文件管理和分享能力以对应网盘当前接口状态为准。
